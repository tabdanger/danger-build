The dashboard talks to the GitHub API straight from this page, so it needs a token. It stays in this browser only. Make a fine-grained token at github.com → Settings → Developer settings → Personal access tokens, scoped to your app repos, with Actions: read and write, Contents: read and Metadata: read.

Builds are triggered with workflow_dispatch, so each workflow file needs that trigger.
